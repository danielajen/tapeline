The finding that averages would have hidden

Time from the exchange's own timestamp to arrival. The median says these three venues are comparable. They are not.

Venuep50p95Verdict
binance63.6 ms 73.8 msTight distribution
coinbase77.5 ms 12,801 ms165× its median
kraken40.5 ms 49,179 msBest median, worst tail

Kraken has the fastest median and a p95 of 49 seconds. Reporting "average latency around 60 ms" would have been arithmetically true and operationally useless. The tail is where a market data system actually fails, and only a distribution shows it.

Seven things that broke

Written up as postmortems in the repo. Five are about measurements lying rather than the system failing — which turned out to be the more useful lesson.

  1. Binance trade sides were inverted. Go matches JSON keys case-insensitively when no exact match exists, so "M" silently bound to BuyerIsMaker and flipped the aggressor on every trade.
  2. 59% of Coinbase trades were dropped. One sequence number belongs to the frame, not to each trade inside it.
  3. Scala collections never survived Flink. Kryo does not round-trip them across an operator boundary. No unit test can catch this — in-process there is no serialization at all.
  4. A probe printed "0 quotes" on every run. It called a Kafka tool removed in 7.7, got an empty string, and turned that into a confident zero. Two real bugs were fixed while chasing a number that was never measuring anything.
  5. A latency metric reported 30,000 ms. The true value was 16.9 ms. The harness was timing its own hold, three orders of magnitude off.
  6. The gap detector cried wolf on every Ethereum block. Log indices count all contracts in a block, so a four-token subscription can never see them contiguous. An alarm that fires constantly on healthy data hides the two real ones.
  7. The server could not start on its own defaults. The OLAP URL said ClickHouse while the driver property said Postgres. No test had ever started the real application, so the path an operator actually gets was the only one never exercised.
